# Навык аудита финансового API

- **Дата:** 2026-10-10
- **Запрос:** создать навык, который проверяет текущие ответы финансового API, находит проблемы на стороне сервера (регистр, несуществующие валюты и т. п.) и готовит отчёт для backend-разработчиков, в том числе в PDF.

## Что сделано

Навык `finance-api-audit`: скрипт делает по одному запросу к `/finance1`, `/finance2` и курсам CurrencyFreaks и прогоняет 39 проверок по каталогу (HTTP, структура, статусы, суммы, коды валют, сверка источников, курсы). На выходе отчёт `report.md` в формате «где, пример, влияние, как исправить»; агент перепроверяет находки и переписывает резюме. PDF собирается через установленный Chrome/Edge, без новых зависимостей.

## Решения и риски

- Список ISO 4217 берётся из `Intl.supportedValuesOf('currency')` (ICU в Node), без своей таблицы. Редкие коды могут отсутствовать в ICU — тогда будет ложное `CUR-NOT-ISO`, поэтому шаг 2 навыка требует ручной перепроверки.
- Найден латентный риск в самом клиенте: `normalizeCurrency` пропускает любые 3 буквы, а у провайдера есть курсы крипто-тикеров (`BTC`, `SOL`…). Транзакция в `BTC` молча пересчиталась бы по курсу биткоина. В навыке это ловится как `CUR-NOT-ISO`; в клиенте стоит добавить проверку по ISO отдельной задачей.
- Повторный прогон по `--snapshot` перезаписывает `report.md`, и правки резюме пропадут — их нужно вносить последним шагом.
